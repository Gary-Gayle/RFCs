# RFCs

This repository is intended for participants in the Open Secure AI Alliance to
collaborate on Requests for Comments (RFCs) and similar proposals.

These RFCs are intended to start open community discussions around how
organizations can work together to improve AI safety and security. They are
open for community review, discussion, and contribution.
